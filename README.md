# 🏃 MOVE

**Run. Conquer. Repeat.**

Turn your daily run into a journey across Bangladesh.

[**Open the app →**](https://move-app-h2me.vercel.app)

</div>

Every kilometre you actually run with MOVE moves you forward along a real route from Dhaka. Keep running and you reach Cox's Bazar, Sylhet or Khulna, one real town at a time.

## ✨ Features

| | Feature | What it does |
|---|---|---|
| 📍 | **GPS run tracking** | Records the distance you really run, on a live map. |
| 🗺️ | **7 journeys** | Dhaka → Cox's Bazar, Chandpur, Sylhet, Khulna, Rangpur, Rajshahi and Barisal, with real towns as checkpoints. |
| 🏁 | **Results and progress** | See each run's result and how far along your journey you are. |
| 🏆 | **Leaderboard** | Compare your progress with other runners. |
| 📤 | **Share** | Share your run or your journey milestone. |
| 👤 | **Profile and onboarding** | Pick a journey and keep your history. |

> 🚧 MOVE is in active development.

## 🛠️ Tech stack

- **Next.js** (App Router) + **TypeScript**
- **Firebase** for auth and data
- **Leaflet** for maps
- Browser **Geolocation API** for distance
- **Tailwind CSS**

## 🚀 Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000. GPS tracking needs location permission, and HTTPS on a real phone.
